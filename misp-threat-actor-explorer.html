Local-first galaxy exploration

When started with ./start-standalone.sh, the application loads Pivotick and MISP Galaxy directly from the bundled git submodules. Alternatively, download the latest releases or import local files. Indexed data remains in this browser’s IndexedDB for offline reuse.

No web server, backend, account, or API token is required. Open this HTML file directly in a recent Firefox, Chromium, or Edge browser.
